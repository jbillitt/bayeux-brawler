Drop your recorded ARMOUR-HIT sounds here (.wav, .ogg or .mp3 — any filenames).
Every audio file in this folder is loaded at startup and one is picked at random
each time a blow lands on METAL armour (mail, scale, lamellar, gauntlets, boots,
coif). Bare/felt/padded/leather/fur/jester targets — and the snail — use the
flesh sounds instead. If this folder has no audio files, a synthesized fallback
plays.
